Pilas — módulo de Yuvomi

Backend del módulo de pilas: stock, repartos por aparato y lo que está sin ubicar.

Comprobando…

Lo que hace

  • Declaras un stock: tipo, marca, línea y cantidad (24 AAA Duracell Recharge).
  • Repartes: 3 · tren Thomas de Ángel · 12/nov, con la fecha en que las pusiste.
  • Mueves, cambias pilas de un aparato y buscas las que aparecen: todo queda en el historial.
  • Sin ubicar se recalcula solo en cada movimiento; la suma de lugares nunca puede pasar del stock.

La página vive dentro de Yuvomi (menú Pilas) y llama a esta API con tu sesión. Se publica desde la imagen de esta app, así que se actualiza junto con el backend.

Si el módulo no aparece en Yuvomi

  1. Confirma que Yuvomi tiene montada la carpeta de módulos: en Ajustes de esta app vecina, «acceso avanzado a carpetas», /app/modules ← /Home/yuvomi-modules.
  2. Reinicia la app de Yuvomi una vez y vuelve a mirar el menú.
  3. Si aun así no sale, instálalo desde Yuvomi: Settings → Modules → Add custom module con https://github.com/Mxrck/yuvomi-batteries y apruébalo.

Regla de proxy en tu dominio

El módulo llama a /api/extensions/batteries/* en el origen de Yuvomi, así que tu proxy inverso tiene que mandar ese prefijo aquí (Nginx Proxy Manager: Custom locations del host de Yuvomi):

location /api/extensions/batteries {
    proxy_pass http://IP_DEL_UMBREL:8184;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

Sin barra final en proxy_pass, para que la ruta llegue intacta.

Permisos

En Yuvomi, Settings → Household → Roles and permissions: el permiso ext:batteries decide quién escribe. Ojo: el valor por defecto de un módulo nuevo es escritura para todos los miembros; si quieres que alguien solo mire, bájalo a lectura.

Datos y respaldo

Desinstalar esta app borra su carpeta de datos, y con ella el stock y el historial. Antes de desinstalar, guarda un respaldo:

curl -s -H "Authorization: Bearer TU_TOKEN_DE_YUVOMI" \
  https://TU_DOMINIO/api/extensions/batteries/export > pilas.json

Con la app instalada, los datos entran en los respaldos normales de Umbrel.

Un consejo que no es software

Marca físicamente las recargables —una letra o un color por línea— para que al abrir un aparato sepas si esas pilas son las tuyas o unas alcalinas cualquiera. Con eso el registro deja de depender de la memoria.
