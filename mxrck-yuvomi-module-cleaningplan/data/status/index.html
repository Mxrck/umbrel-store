Cleaning plan · sidecar

Servicio que guarda el plan de limpieza del módulo de Yuvomi. No tiene interfaz propia: se usa desde dentro de Yuvomi.

Comprobando…

Para activarlo

  1. En Yuvomi, Settings → Modules → Add custom module con https://github.com/la3mmchen/yuvomi-cleaningplan, y apruébalo en la lista de módulos activos. Necesita MODULES_ALLOW_WEB_INSTALL=true y la carpeta de módulos montada.
  2. En tu proxy inverso, manda /api/extensions/cleaningplan/ del dominio de Yuvomi a este app (puerto 8183 de este servidor).
  3. En Settings → Household → Roles and permissions, da ext:cleaningplan a quien deba usarlo: write para editar el plan y generar, read para verlo.

Esta app no escribe en la base de datos de Yuvomi: crea tareas por su API y valida la sesión del usuario en cada petición. Su plan vive en su propia base SQLite, dentro de la carpeta de datos de esta app.
